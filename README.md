## 🚀 Featured Projects

### 📄 DrRag — AI Document Q&A SaaS
Document question-answering platform built for Indian developers.
- Custom document processing pipeline (`pdfplumber`, `python-docx`) feeding a RAG workflow
- Embeddings via the Hugging Face Inference API to stay within hosting memory limits
- Groq-backed LLM layer designed around free-tier capacity
- **Stack:** Python · FastAPI · Next.js · Supabase · Groq · Hugging Face

### 🔬 ResearchLens — AI Research Companion
An assistant that speeds up the research workflow.
- Modules for **paper search, literature review, gap finding and novelty checking**
- Hybrid **Groq + Gemini** LLM strategy; persistence with **Supabase pgvector**
- Designed to run entirely on free-tier hosting
- **Stack:** Python · FastAPI · Supabase pgvector · Groq · Gemini

### 📈 Pitch2Scale — AI MVP Blueprint & Pitch Deck Generator
Turns a startup idea into an MVP blueprint and pitch material.
- Local LLM inference with **Llama 3 via Ollama**
- Automated PDF report generation with ReportLab
- **Stack:** Python · FastAPI · Next.js · Ollama · ReportLab

### 💻 Nitz — Terminal AI Coding Companion
A CLI coding assistant with personality, built with Indian developers in mind.
- **Tanglish** support and Indian-developer context awareness
- Rich terminal UI with a Tkinter companion window
- **Stack:** Python · Gemini 1.5 Flash · Rich · Tkinter

### 🌉 BRIDGE — Cross-Platform AI Conversation Chrome Extension
Capture an AI conversation and continue it on another platform.
- Works across **ChatGPT, Claude, Gemini and Perplexity**
- Bring-your-own Gemini API key flow (no OAuth needed)
- **Stack:** JavaScript · Chrome Extension APIs · Gemini API

### ♟️ Sadhurangam — Multiplayer Chess
Real-time multiplayer chess in the browser.
- Game rooms, friends, timers and **spectator mode**
- Live sync with **Supabase Realtime**
- **Stack:** React · Vite · chess.js · react-chessboard · Supabase
