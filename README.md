## 🚀 Featured Projects

### 📈 [Pitch2Scale](https://github.com/nithinsj-code/Pitch2Scale) — Startup Idea → Investor-Ready Deliverables
Turns a raw startup idea into a full pitch package using a dual-LLM architecture.
- Generates a **pitch deck outline, market analysis (TAM/SAM/SOM), speech script** and conversational **AI coach feedback**
- **Dual-LLM routing:** Groq for fast generation, Gemini for deeper reasoning
- Exports to **PDF and PowerPoint**; projects saved per user with Supabase Auth + Row Level Security
- **Stack:** Next.js · TypeScript · Tailwind CSS · Supabase · Groq · Gemini · Zustand · Zod

### ✍️ [DraftRex](https://github.com/nithinsj-code/draftrex) — Multi-Client Voice Matching for Freelance Writers
Build a voice profile per client from writing samples, then rewrite drafts to match each client's style — without mixing voices across accounts.
- Per-client style profiles with auth and persistent storage
- LLM rewriting powered by Groq (Llama 3.3 70B)
- **Stack:** Next.js · FastAPI · Supabase (Auth + PostgreSQL) · Groq · Vercel · Render

### ♟️ [Sadhurangam](https://github.com/nithinsj-code/sadhurangam) — Real-Time Multiplayer Chess (Tamil Edition)
A premium multiplayer chess app with a custom neumorphic UI.
- **Low-latency real-time gameplay** with instant move sync via Supabase Realtime
- Secure auth and game data protected by Supabase Auth + RLS; fully mobile responsive
- **Stack:** React · Vite · chess.js · react-chessboard · Supabase · Vercel

### 🎨 [SketchGPT](https://github.com/nithinsj-code/SketchGPT) — Draw, and AI Guesses It
Sketch on a digital canvas and let a Gemini vision model analyse and guess your drawing in real time.
- Smooth HTML5 canvas drawing interface with a minimalist neo-brutalist design
- Responsive on desktop and mobile; deployable on Vercel + Render
- **Stack:** React · HTML5 Canvas · Flask · Gunicorn · Google Gemini API

### 🎯 [Prep4Future AI](https://github.com/nithinsj-code/prep4future-ai) — AI Career Preparation Platform
Takes a candidate from resume upload to interview readiness in one workflow.
- **ATS resume scoring**, keyword-gap detection and section-wise feedback against a target job description
- **Mock interviews** with voice input, answer evaluation and an AI career coach
- Downloadable career-readiness PDF reports
- **Stack:** React · TypeScript · FastAPI · Groq · PDF parsing · Vercel · Render

### 🌿 [NaturoCrop](https://github.com/nithinsj-code/naturo-crop) — AI Farming Assistant
Helps farmers detect plant diseases and plan their crops using ML and LLMs.
- **Leaf-image disease detection** across 38 categories (MobileNetV2) with Llama 3 explanations and treatment plans
- **Crop strategy generator** from location, soil nutrients (N, P, K, pH) and season
- **Stack:** Python · FastAPI · TensorFlow/Keras · Llama 3 (Ollama) · HTML/CSS/JS
